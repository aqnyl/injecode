## Introduction / 项目介绍

Injecode is an integrated companion for modern AI-assisted development. It streamlines the workflow between your local/remote codebase and Large Language Models (LLMs) by solving two fundamental bottlenecks: **Context Assembly** and **Code Application**.

Injecode 是一款专为现代 AI 辅助开发设计的集成工具。它解决了本地/远程代码库与大语言模型（LLM）交互中的两大核心瓶颈：**上下文编排**与**代码应用**。

---

## Core Capabilities / 核心功能

### 1. Semantic Code Assembly / 代码逻辑提取

Injecode shifts the focus from physical file structures to logical feature sets.
Injecode 将开发者的关注点从物理文件结构转向了逻辑功能集。

*   **Logical Grouping**: Aggregate code from disparate directories (e.g., Frontend and Backend) into a single "Feature Context".
    **逻辑分组**：将分布在不同目录（如前端与后端）的代码聚合到同一个“功能上下文”中。
*   **Token Optimization**: Select only relevant functions or files to fit within model context windows without wasting tokens.
    **Token 优化**：仅提取相关的函数或文件，在不浪费 Token 的前提下完美适配模型的上下文窗口。
*   **Hybrid Sources**: Support for local file systems and SSH-connected remote environments.
    **混合数据源**：同时支持本地文件系统与通过 SSH 连接的远程环境。

### 2. Precise Code Injection / 精准代码注入

The "Code Injector" automates the process of applying AI-generated suggestions back into your source files.
“代码注入器”实现了将 AI 生成的建议全自动应用回源文件的流程。

*   **Deterministic Patching (Protocol 3)**: Uses the `$$$$` delimiter system to target and replace specific blocks with zero risk of misplacement.
    **确定性补丁 (Protocol 3)**：使用 `$$$$` 定界符系统精准定位并替换特定代码块，消除误操作风险。
*   **Full Overwrite (Protocol 1)**: Reliable deployment for newly generated files.
    **全量覆盖 (Protocol 1)**：针对新生成文件的可靠部署方案。
*   **Safety First**: Built-in visual diffing and one-click undo (Ctrl+Z) ensure your codebase remains stable.
    **安全至上**：内置可视化 Diff 对比与一键撤销 (Ctrl+Z)，确保代码库的稳定性。

### 3. Visual Prompt Engineering / 可视化提示词工程

A structured workspace to design complex prompts without manual text concatenation.
一个无需手动拼接文本、用于设计复杂提示词的结构化工作区。

*   **Block-Based Layout**: Reorder instruction, code context, and requirements via drag-and-drop.
    **卡片式布局**：通过拖拽即可重新排列指令、代码上下文及需求说明的顺序。
*   **Real-time Analytics**: Live token estimation to monitor usage before sending requests to the LLM.
    **实时分析**：在向模型发送请求前，通过实时 Token 预估监控消耗情况。

## Database & Remote Tools / 数据库与远程工具

*   **Schema Extractor**: Automatically generates token-efficient representations of database schemas and sample data.
    **架构提取器**：自动生成节省 Token 的数据库表结构与样本数据表示。
*   **Execution Bridge**: Execute shell commands on local or SSH targets and pipe results (logs, errors) directly into the AI prompt.
    **执行桥接**：在本地或 SSH 目标上执行 Shell 命令，并将结果（日志、错误）直接导流至 AI 提示词中。
